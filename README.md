# منظّم الوقت — Time Manager

موقع ويب احترافي لتنظيم الوقت والمهام والمواعيد، يعمل بالكامل في المتصفّح ويحفظ بياناتك محلياً على جهازك.

## كيفية التشغيل

1. افتح الملف `index.html` في أي متصفّح حديث (نقرة مزدوجة تكفي).
2. لا حاجة لأي خادم أو تثبيت — كل شيء يعمل من ملفات ثابتة (HTML/CSS/JS).

> ملاحظة: إشعارات التذكير (Notification API) تتطلّب HTTPS أو `localhost`، لذا عند فتح الملف مباشرة عبر `file://` ستعمل كل الوظائف عدا الإشعارات المنبثقة (سيتجاهلها التطبيق بأمان).

## الميزات

- **لوحة التحكم**: إحصائيات اليوم، المهام المستحقة، المواعيد القادمة.
- **المهام**: إضافة/تعديل/حذف، أولوية، تاريخ استحقاق، فئة، بحث وتصفية، إنجاز بعلامة ✓.
- **المواعيد**: تقويم شهري تفاعلي مع نقاط على الأيام التي فيها مواعيد، وإدارة مواعيد اليوم.
- **مؤقّت التركيز (بومودورو)**: تركيز 25 دقيقة + استراحات قصيرة/طويلة، مع عدّاد جلسات يومي.
- **الإحصائيات**: توزيع المهام حسب الفئة، معدّل الإنجاز الأسبوعي، وإجماليات.
- **الإعدادات**: وضع ليلي/نهاري، تصدير واستيراد البيانات (JSON)، ومسح البيانات.
- حفظ تلقائي في `localStorage`.

## مراجعة الكود وإصلاح الأخطاء

تمت مراجعة الكود وإصلاح الأخطاء التالية:

1. **الشارات (badges) لا تُخفى**: خاصية `hidden` كانت تتجاوزها قاعدة `display: grid` في CSS. أُضيف `[hidden] { display: none !important; }`.
2. **دمج الإعدادات سطحي**: عند تحميل بيانات قديمة/جزئية كانت قيم مؤقّت بومودورو (`short`/`long`) تختفي وتصبح `NaN`. أُضيفت دالة `mergeSettings` لدمج عميق.
3. **فرز المهام قد ينتج `NaN`**: عند وجود أولوية غير معرّفة. أُضيفت قيمة افتراضية `?? 9`.
4. **تذكير قد يرمي استثناء**: إذا كان الموعد بلا وقت. أُضيف فحص `!a.time`.
5. **كود ميت**: حذف المصفوفة غير المستخدمة `WEEKDAYS_SHORT`.
6. **عدّاد الجلسات اليومي**: يُصفَّر تلقائياً عند بدء يوم جديد.
7. **تحسين**: عنوان "مهام اليوم" أصبح "المهام المستحقة" ليطابق المنطق (يعرض أيضاً المتأخرة)، وإضافة بديل لخاصية `color-mix`.
